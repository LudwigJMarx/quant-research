# quant-research

This repository holds the code and the derived results of my published working papers in quantitative finance, one folder per paper. Each folder lists which file produces which number and figure of its paper, so that a reader with access to the same data can reproduce the results. Licensed price data are not included. The code is under the MIT license (see LICENSE).
